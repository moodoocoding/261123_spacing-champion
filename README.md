# 띄어쓰기 1등은 누구?

2026 충북 AI 페스티벌 체험 부스용 웹앱입니다. 초등학생이 기획하고 만든 띄어쓰기 퀴즈 게임을 업그레이드했습니다.

- `index.html`: 업그레이드한 앱 (화면을 나눠 2~4명이 같은 문제를 동시에 푸는 대결, 누르면 실제로 벌어지는 띄어쓰기 칸, 이름 입력, 명예의 전당 TOP 10 랭킹, 틀린 곳 표시, 허용 띄어쓰기 인정, 선생님 관리)
- `원본_학생작품.html`: 학생이 만든 원본

랭킹은 앱을 연 기기의 브라우저에만 저장됩니다.
